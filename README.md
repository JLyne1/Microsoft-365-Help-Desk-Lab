# Microsoft-365-Help-Desk-Lab

A self-directed IT support project exploring Microsoft 365 services, common end-user issues, troubleshooting procedures and technical documentation.



###### Project Overview

This project aims to expand my knowledge of Microsoft 365 and develop a better understanding of how IT support teams diagnose and resolve common user issues.

Through independent research, practical exercises and simulated support scenarios, I will explore the tools and processes used by help desks and IT support technicians.

The project is intended to complement my existing IT and cloud knowledge while developing skills relevant to entry-level Help Desk, Service Desk and IT Support Technician roles.



###### Project Objectives

I aim to develop my understanding of the following areas:

* User accounts and licence management
* Identity and access management
* Microsoft 365 applications and services
* Troubleshooting procedures and problem diagnosis
* Permissions and access control
* IT ticket handling and documentation
* Security fundamentals and safe support practices

I will demonstrate my learning through technical notes, research documentation, step-by-step troubleshooting guides and simulated support tickets. Where possible, I will also include screenshots and evidence of practical exercises.



###### Project Scope

The project will focus on researching and practising support scenarios involving Microsoft 365 services and related technologies, including:

* Windows and user accounts
* Outlook and email troubleshooting
* Microsoft Teams
* OneDrive and SharePoint
* Office applications, including Word and Excel
* Identity, access and basic administration concepts
* Other relevant Microsoft 365 services as the project develops

I will use free Microsoft resources and available web applications wherever possible. Access to business administration features and certain practical exercises may be limited by the absence of a paid Microsoft 365 business subscription.

Where hands-on testing is not available, I will use official documentation and clearly identified simulated scenarios to develop my understanding.



###### Tools and Resources

* Operating system: Windows 11
* Applications: Available Microsoft 365 web applications and other relevant free tools
* Documentation and version control: GitHub and GitHub Desktop
* Learning resources: Microsoft Learn, official Microsoft documentation, troubleshooting guides, and Microsoft Support resources



###### Project Documentation

Project work and findings will be organised into the following folders:

* Documentation/ — Research notes, technical concepts and learning summaries.
* Support-Tickets/ — Simulated incidents, investigation steps, findings and resolutions.
* Troubleshooting-Guides/ — Step-by-step procedures for common support issues.
* Screenshots/ — Relevant screenshots demonstrating practical exercises, with sensitive information removed.
* References/ — Official documentation and learning resources used throughout the project.



###### Progress Log

I will update the repository as the project progresses, recording completed tasks, key findings, troubleshooting experiences and lessons learned.

The documentation will be developed incrementally to reflect my growing understanding of Microsoft 365 and its application to entry-level IT support.
