###### Ticket HD-001 - User cannot access Teams

“I can sign in to my Windows laptop, but when I open Microsoft Teams, it asks me to sign in again. My password seems to work, but I still can't get in.”





* What are three possible causes of this issue?

  * User attempting to use the Windows sign-in instead of the Microsoft sign-in.
  * User may not be authorised to access Teams.
  * User's session may be expired or cache may need clearing.

* What questions would you ask the user before attempting a fix?

  * Which device are you attempting to log in from?
  * When was the last time you were able to log in to Teams?
  * Have you logged in to any other Microsoft 365 apps today?
  * What exactly happens after you enter your credentials? (Error message, MFA prompt, etc.)
  * Are you using the Teams desktop application or the web version?

* What basic checks would you perform first?

  * Is the user's device connected to the Internet? (Prevents time-out issues).
  * Is the user using the correct organisational account?
  * Is the user able to log in to other Microsoft 365 apps?
  * Try accessing Teams through the web browser instead of the desktop application, or vice versa. Isolate the problem.
  * Does the user receive a specific error message when attempting to log in?
  * Does the user receive an MFA challenge when attempting to log in?

* When might you escalate the ticket to an administrator?

  * The account appears locked out and I don't have permission to unlock it.
  * Conditional Access policies are blocking access and require administrator investigation.
  * The user doesn't have the necessary licence or application permissions.
  * Authentication failures persist after basic troubleshooting and the cause cannot be established.
  * Password or account changes exceed my authorised permissions.



* What security precautions should the help desk follow while investigating?

  * Do not ask users for their passwords or MFA verifications.
  * Verify the user's identity.
  * Do not ask users to approve unexpected authentication prompts.
  * Use authorised tools and procedures during account investigations or when changing access permissions.
  * Protect users' personal information and any sensitive organisational information.
